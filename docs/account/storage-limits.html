Storage limits

Every workspace has a limit on how much it can hold, and every file has a limit on how large it can be. They exist so one workspace cannot use up the storage the whole service shares.

The limits

Limit Default
Largest single file 2 GB
Total storage per workspace 10 GB

Deleting files frees the space immediately.

What you see when you hit one

An upload that would cross a limit is stopped, and the message says which limit it was: either the file is too large on its own, or the workspace has no room left. Nothing is partially saved, so you can delete some files and upload again.

If you are close to the workspace limit, a large upload can fail part of the way through. Free up space first rather than retrying.

File types

Uploads are checked for what they actually contain, not just their name. Web pages, scripts, and programs are refused even when renamed to look like a video or an image. Footage, audio, images, and subtitle files are unaffected.

Uploads are also scanned for viruses. A file that is infected, or one that cannot be scanned, is rejected and not stored; ordinary media is unaffected.

If a real media file is refused, tell us which format it was.
